# Watch TV

Sideload **Watch-tv.apk**. Separate from the phone app (`com.example.watchmobile.tv`).

**Controller:** D-pad moves focus. First poster is focused on Home. Left column is the menu — D-pad left onto it, up/down through items, A to select, B back.

**Playback:** H.264 720p/1080p is the safest. HEVC/4K may fail on low-end sets.

Use Ethernet (or solid Wi-Fi) on the same network as the PC.

The APK belongs on a GitHub Release, not in git.
